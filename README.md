# Bounce Tales — Native PS5

An unofficial native PS5 port of **Bounce Tales**, the 2008 Nokia J2ME platformer.
The game code was translated from Java to C++ and runs natively on a jailbroken PS5,
with DualSense controls, a 16:9 widescreen view, sharp full-resolution text and MIDI music.

PS5 port by **Youss Riaal**.

> **This release contains no original game files.** You need your own copy of the
> original Bounce Tales `.jar` (Nokia J2ME version, v2.0.x). The game reads its
> artwork, levels, text and music from that file.

## Install

1. Extract `BNTL00001-v<version>.zip` and copy the `BNTL00001` folder to `/data/homebrew/`
   (or your usual homebrew location).
2. Copy your own Bounce Tales `.jar` into `/data/BounceTales/`.
   Any file name ending in `.jar` works; if it is not found, rename it `game.jar`.
3. Activate your usual jailbreak, kstuff and ShadowMount+ setup, scan, then launch **Bounce Tales**.

If the `.jar` is missing, the game shows a setup screen; copy the file over FTP and press **Cross**.
Saves are kept in `/data/BounceTales/`. A log is written to `/data/BounceTales/bouncetales.log`.

All 240×320 Bounce Tales v2.0.x jars share the same game files and differ only in their
languages; the port picks the first valid `.jar` it finds.

## Controls

| DualSense | Action |
|---|---|
| D-pad / left stick | Move, navigate menus |
| Cross | Jump, select, OK, fire the cannon |
| Square / L1 / R1 | Change ball form |
| Circle / Options | Pause menu, back |
| Triangle | Left soft key (Select / Yes) |

## How it works

- `src/game.cpp`, `src/game.hpp`: the game logic, translated to C++ from the original
  game's Java bytecode. Generated by `tools/j2cpp.py`.
- `src/jrt.hpp`, `src/platform.cpp`: a small Java/MIDP/Nokia UI runtime (graphics,
  text, MIDI playback, record stores) on top of SDL2.
- `src/main.cpp`: start-up, display, controls and loading the user's `.jar`.
- The game itself supports several phone screen sizes; the port gives it a 480×270 (16:9)
  screen, enlarges it to 1080p with two edge-aware 2x passes, and draws its text at full
  resolution. The English instructions name the DualSense buttons.

## Build

Requirements: Python 3, LLVM/clang 18 with `ld.lld`, the
[PS5 Payload SDK](https://github.com/ps5-payload-dev/sdk) with libc++, SDL2 and libsamplerate
built for PS5 (pacbrew), and the zlib 1.3.1 source.

```
set LLVM_BIN, PS5_PAYLOAD_SDK, PS5_HBROOT, BT_TOOLS (folder containing zlib-1.3.1)
python build-title.py --zip
```

Output: `BNTL00001/` and `BNTL00001-v<version>.zip`. For a desktop build use `make -f Makefile.host`
(Linux, SDL2) and run `build-host/bouncetales --jar <your .jar>`.
